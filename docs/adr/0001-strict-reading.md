# ADR 0001: 严格读取，坏数据默认失败

## 状态

已采纳（0.2.0）。

## 决策

1. 文件名、ZIP 结构、CSV header、行时间戳、K 线不变式全部校验。
2. 文件级损坏没有降级路径，始终失败。
3. 行级损坏默认 `fail`；显式 `skip` 才继续，并统计数量、保留最多 5 条样本。
4. 根目录不存在、无匹配文件、日期窗口剪空都给结构化错误，不返回空表掩盖问题。

## 理由

1. 归档是研究输入；静默丢行或错位合并会污染下游结论。
2. 文件级错误通常意味着下载不完整或目录放错，继续读取没有意义。
3. 行级错误可能是单行噪声，保留 `skip` 给调用方显式选择。

## 代价

1. 一个坏文件会阻断整次读取，需要重新下载。
2. 调用方必须处理 `Error`，不能假设总能拿到部分数据。
